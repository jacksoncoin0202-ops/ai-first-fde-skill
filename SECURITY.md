# Security and Public Safety Policy

This is a public repository. Treat every contribution as publishable to the open internet.

## Never include

- customer names unless already public and explicitly authorized
- employee names or identifiable personal details
- internal system URLs
- API keys, tokens, passwords, session cookies, private keys
- contract terms, non-public pricing, invoices, legal documents
- private architecture diagrams
- detailed security weaknesses
- identifiable internal politics
- non-public customer deployment outcomes

## Required redaction style

Use anonymized labels:

- "匿名日本製造業"
- "匿名台灣技術服務公司"
- "匿名香港金融服務公司"
- "Department A / Department B"
- "Internal ticketing system"
- "Document repository"

## Reporting a security issue

Open a private security advisory if available, or contact the maintainer directly. Do not disclose sensitive details in public issues.
