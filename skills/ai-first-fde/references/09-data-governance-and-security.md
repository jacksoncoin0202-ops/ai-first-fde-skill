# Data Governance and Security

## Minimum controls

- Data inventory
- Owner for each data source
- Classification for sensitive data
- ACL metadata on documents
- Least privilege access
- Audit logs
- Human approval for high-risk output
- Retention and deletion rules
- Prompt injection testing
- Public-safe redaction process

## Red flags

- One shared admin account
- No document owner
- Mixed customer folders
- No access logs
- Copy-pasted secrets in documents
- AI connected directly to production write APIs without approval
